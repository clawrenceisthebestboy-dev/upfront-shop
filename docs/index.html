How to install

  1. Click Download for Windows above.
  2. Open the downloaded UpFrontShopSetup.exe.
  3. Click through the installer wizard (Next → Install → Finish).
  4. Launch Up Front Shop from the Start Menu.
Heads up: the first time you run the installer, Windows SmartScreen may show a blue warning ("Windows protected your PC"). Click More info, then Run anyway. The installer is unsigned but safe — built automatically on GitHub from our public source code.
